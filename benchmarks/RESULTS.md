# Overhead benchmark results

Generated by `python benchmarks/overhead.py`. See [docs/performance.md](../docs/performance.md) for methodology and interpretation.

- Python 3.11.9 on Windows 10 (AMD64), 16 logical CPUs
- Processor: Intel64 Family 6 Model 154 Stepping 3, GenuineIntel
- Each value is the median over 5 rounds (each the median of 5 timeit runs) of the mean time per call. Ratios are computed within each round.
- **Reference:** the bare OpenTelemetry SDK (one span + one histogram record, no library code) costs **83.64 µs** in this run. "vs OTel" columns are relative to it, which is more stable across machines than absolute times.
